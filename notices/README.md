# Supplemental dependency notices

These verbatim public fixed-source grants supplement notices shipped in the installed packages. `provenance.json` binds each original text, version, source and SHA-256. The OpenTelemetry copyright extraction is a preserved installed-file header, not an invented upstream NOTICE. Teams release-tag/source package versions differ; that limitation is retained.

The image also retains original package notice/assets, Node's bundled third-party LICENSE, npm/Corepack/Yarn notices, Debian copyright files and referenced common licenses. Final image inventory records actual included files; this directory is not a substitute for that inventory or required corresponding-source material.

The two named grant/applicability questions in provenance remain unresolved. This local synthetic artifact has no blanket distribution, legal or security clearance. External CBM/private Kibana artifacts are not bundled. No source grants were reconstructed from SPDX metadata.

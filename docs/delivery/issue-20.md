## 实现与验收

| 验收 | 实际可观察结果 |
| --- | --- |
| 三角色读取／导出 | C `read/export` 每次取得宿主当前授权，并记录实际访问者及角色。请求人须是原案主／租户／固定会话且仍有全部资源权限；业务复核人须有明确案例分配，只返回报告与证据，不返回视图、输入输出、审计或交付详情；技术角色须有明确案件及完整资源范围，才返回脱敏完整记录。返回前再次检查当前授权和删除闸门；撤回分配、角色／资源失效及案件外请求均不披露。角色来自宿主 grant，调用者附加的案件、资源、审批或角色字段不能覆盖冻结范围。 |
| 净化与历史访问 | 导出保持服务端固定披露范围，使用原有本案净化记录；不保存凭据或可逆原值映射，案例代号继续绑定本案。C 操作及生命周期能力均未注册为 Agent 工具，模型即使提供生命周期负责人身份字段也不能导出历史或触发删除。角色控制失败与生命周期／存储失败只返回有限安全代码，不透传原始错误。 |
| 四类保留触发 | 仅获准生命周期路径可调用 `Retention.recordTrigger/purgeDue/deletionStatus`。登记 MVP 验收、POC No-Go、终止、决定不进入 MVP 四种事件，保存触发 ID、类型、UTC 决定时间、登记时间、POC 范围及 30 天截止日。时间须是有效规范 UTC，拒绝未来／无效日期。精确重放保持原事件，冲突复用 ID 拒绝；多个事件取最早截止日，不因后来的决定延长保留。 |
| 到期与运行隔离 | 截止前 1ms 保留，到点封闭资料；观察到到期后持久保存 `closedAt`，UTC 回拨或重启不能开放旧记录。获准宿主执行 `purgeDue` 时先保存删除意图并封闭运行路径，取消／关闭本案运行任务、清理上下文和代号映射；旧 A 结果、C 导出及迟到模型结果都不能披露或重建资料。控制等待／本地关闭等待各有 5 秒上限及有界位置，超时保留部分完成状态；原关闭尚未确认时，重复删除不能误报完成。 |
| 受控删除与收据 | 原生事务删除完整案件、版本化记录与案件审计，删除已启用且通过本地固定配置验证的受控临时／备份／宿主模拟副本，随后执行 VACUUM，核验 `secure_delete=ON`、空闲页 0、DELETE journal、内存临时表及具名存储清单。记录库 journal／WAL／SHM 在残留检查范围内，只有确认不存在才可成功；未知文件或未完成清理使收据为 partial。生命周期意图、最终收据均持久化；记录删除、复制清理、压缩或最终收据提交失败均不得返回成功，重启后可重试。 |
| 最小账本与迁移 | 保留 POC 总费用、原调用费用／来源／未知槽、幂等事件摘要、最小交付键／状态及生命周期收据。预算的原完整身份／会话／资源绑定改为规范 SHA-256 摘要；schema 1/2→3 迁移在事务中保留原预留、结算和幂等关系，迁移故障回滚。删除后原调用仍可幂等结算，收费／终止未知保持预留，不能借清理或重启获得新准入。已关闭项目不恢复调查、模型或交付。 |

`CaseRecords` 的返回范围显式区分 full 与 report_evidence，生命周期是宿主路径，Agent 只持有原有调查闭包。宿主生命周期负责人登记项目事件并调用 `purgeDue`；本票没有部署真实定时任务或授权外部平台管理操作。

## 原生删除范围与限制

所有样本来自本次测试创建的私有临时目录，没有打开既有用户数据库。数据连接继续使用单实例独占运行锁和 DELETE journal；运行锁数据库及可能存在的锁 journal 不存案件数据，作为最小运行锁资料保留并纳入具名文件标记扫描，不删除锁文件来“释放”锁。复制与残留检查绑定数据库打开时的同一 canonical root，父路径别名重定向不能让清理触及另一棵目录；拒绝悬空链接、越界配置及未通过权限／文件类型检查的副本。

仅实现并启用固定的 `synthetic-local-private-files-1` 副本配置：本服务私有目录下、普通单链接文件组成的合成临时／备份／宿主副本。配置同时验证范围、私有权限及文件形态，逐项返回删除结果。未知备份配置和宿主快照配置拒绝启用；默认没有任何备份或快照。这里的 backup／host_copy 是合成本地副本的测试类别，不证明真实备份系统、宿主自动复制或快照已经验证。

删除收据列明范围、开始／本次执行结束时间、逐项结果、保留的最小状态与局限；partial 表示此次尝试结束但删除未完成。具名文件检查及 VACUUM 不能证明 SSD、COW、已解除链接文件、swap、原始设备或硬件层取证擦除，也不证明 Teams／模型供应商副本已删除。SQLite VACUUM 是同步维护；本次小型合成库验证成功，未证明真实大卷的耗时上限或硬件断电保证。5 秒界限针对异步控制和本地运行关闭等待，不宣称 AbortSignal 能终止同步 VACUUM。

# #17 — 幂等、容量、取消与跨案隔离

对应 [#17](https://github.com/GordonFP/bau-support-agent/issues/17) 与父规格 [#14](https://github.com/GordonFP/bau-support-agent/issues/14)。基于 `99cd1a1`，包含已独立提交并集成的评审修复 `c2d8dc0`；验证日期 2026-10-20。

## 实现与验收

| 验收 | 实际可观察结果 |
| --- | --- |
| 受理与幂等 | SHA-256 摘要取可信租户、固定会话和平台事件 ID 的无歧义元组。受控 admission Port 确认后才完成 accepted 审计和应答；并发重复只调查一次。重复案返回当前视图并重新校验案主与授权，满额时仍可获取原案。确认后审计失败保留停止态，重试不会启动调查。 |
| 入站与容量 | D 的合成私聊适配器在 UTF-8 解码、JSON 解析之前检查原始字节数，64 KiB 可受理、超一字节拒绝；身份仅取宿主固定信封，正文身份字段被拒绝。A 同样在复制／排队前限制业务正文。未结束案与未确认结束的受理控制合计最多 32；等待案计入容量。受理前授权／审计／确认的本地等待最多 180 秒；超时不释放仍未确认结束的控制占用，迟到确认只保留停止态，不启动调查。补问操作另限每案 32 个，重复事件共用操作，不无限延长 replyTail。 |
| 查询与取消 | A.get／cancel 要求完整可信主体、租户和目的会话，并每次检查当前授权。未知、他人、缺失或畸形身份均返回同一 denied。本人取消幂等，立即使领域和视图终止、取消信号及期限生效，清除本案原值映射；取消后不再接纳取证／模型结果。 |
| 隔离 | 每案与轮次保留自己的上下文、闭包、信号、工具结果、任务和代号。验证两名合成获准用户交错执行，A 的取消、重复重连和迟到模型结算不改变 B 的状态、证据或目的会话。调用／证据引用均包含本案及轮次；无跨案证据缓存。 |
| 期限与收尾 | 模型最多 60 秒，日志／代码最多 30 秒，均与本轮剩余 180 秒取小值；授权／审计／预留等待也在调用时限内。持续 progress 只作有限净化并丢弃，不延长期限。即使 Agent 捕获超时异常也不能继续调查。终止后的审计／abort／close 本地等待共用最多五秒，迟到结果不重新占用调查流程。 |
| 未知上游 | 本地停止与 upstream settled 分开。原模型调用的未知费用保留预留，不按零结算；迟到有实际 usage 才以原调用 ID 结算，迟到正文只记 discarded，不重新净化进已清映射或交付。已发起但未确认的交付保留 unknown，重复事件不自动重发。 |

采用既定 A（受理、补问、查询／取消）、B（Agent／受控工具／模型）、C（审计、预算、admission）和 D（合成入站／固定目的交付）公开边界，按失败行为→最小实现→回归推进。容量、已存在行为与故障组合再作验收边界回归；没有测试私有实现方法。

本次还解决 #16 评审跟进：Agent 在歧义日志之前读取代码、补问恢复后再次读取代码，原来因证据 ID 冲突停止；现在每次检索生成本案／本轮唯一引用，保留各自实际审计凭证。公开测试验证恢复成功且两份代码证据来源可区分。先前草稿资料失效和统一具名限制的修复见 [独立记录](review-through-16.md)。

## 验证结果

沿用 [#15 精确工具链](issue-15.md)：Node.js 24.22.0、TypeScript 7.0.2、@types/node 24.10.0。未新增／升级外部依赖；SHA-256 使用 Node 内置 crypto。

```sh
export PATH=/tmp/node-v24.22.0-darwin-arm64/bin:$PATH
npm ci --ignore-scripts --offline
npm run typecheck
npm run build
npm test
git diff --check
```

- 离线安装、独立类型检查与构建通过。
- 70 项行为测试通过，含 42 项既有行为、#16 代码证据跟进，以及 27 项本票场景：64 KiB／超限、受理与回复队列、容量恰满与越界、摘要作用域、确认前不应答、撤权／畸形身份、幂等取消、两用户交错、未知交付、29／30 秒与 59／60 秒、剩余时限截断、持续进度、排队等待、受理前控制挂起／迟到确认、五秒收尾、迟到结算及禁止继续调查。
- 交付记录引用检查和差异格式检查通过。

此票只交付 G0 受控 Mock 保证，真实路径继续关闭。没有实际 Teams、Pi、MCP、模型、生产日志或 GitLab 联调；没有证明真实身份认证、SDK 取消传播、上游物理并发槽何时 settled 或真实退款。Mock admission 与费用记录均为进程内受控 Port，重启持久性由 #18 补齐，原子全局并发／费率账本由后续票补齐。保留的未知调用只可按原调用审计对账，不宣称已终止上游；这些限制不以本票离线结果消除。#15 记录的 Node 安全更新通知仍为待核实更新门禁。
